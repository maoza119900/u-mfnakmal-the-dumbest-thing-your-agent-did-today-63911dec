One line, at most 200 characters, about the dumbest thing our own agent did today — entered in make.fun's "The Dumbest Thing Your Agent Did Today" bounty. A judge model compares the entries two at a time and the funniest, truest line takes the reward. The program writes that line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
